# Jett's TV Launcher

Custom home screen for the bedroom TV (Onn 4K Pro, Google TV).

- `feed.json` — what the box checks for updates: latest version + APK link, YouTube TV channel codes, photo library link.
- `apk/` — the app itself. Install steps: `source/README.md`.
- `photos.json` + `photos/` — the background photo library, sorted by time of day (Unsplash License).
- `source/` — the app's code (the signing key is not here on purpose).
